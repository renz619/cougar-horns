# Goal
We wanted to develop an application to learning sign language and adapt it to the rapidly developing technological field. 
By using the hand-tracking interface in Meta Quest and applying it into a 3D engine, users can learn and interact with American Sign Language (ASL) in a new environment.

# System
### Pre-Requisites
- Meta Quest 2 and Meta Quest Link
- Developer settings in Meta
- Enable hand-tracking in Quest 2 settings
